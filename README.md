# Arte & Personalidade 🎨

Landing Page criada para uma loja de presentes personalizados. O foco do projeto foi criar uma interface bonita e funcional utilizando apenas **HTML, Tailwind CSS e JavaScript Puro**, sem frameworks pesados.

### ✨ O que o projeto faz?

- Mostra produtos em destaque e promoções.
- Permite filtrar produtos por categoria ou buscar por nome.
- **Carrinho de compras:** O usuário adiciona itens e vê o total atualizado.
- **Checkout:** Ao finalizar, o site gera uma mensagem automática com o resumo do pedido e envia para o WhatsApp do vendedor.
